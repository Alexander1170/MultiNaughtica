# Contributing

MultiNaughtica is a fork of [Nitrox](https://github.com/SubnauticaNitrox/Nitrox) that is shared as it is, with no support promise. There is no team behind it, so nobody is obliged to answer issues or merge pull requests.

If you want to change something:

- Fork it and do what you like with it; the licence (GPL v3, see `LICENSE.txt`) allows that.
- For anything that also helps stock Nitrox, send it to [the Nitrox project](https://github.com/SubnauticaNitrox/Nitrox) as well, and read their [contribution guide](https://subnauticanitrox.github.io/Documentation/). The code of this fork follows Nitrox's style (`.editorconfig`).
- Run the tests before you share a change: `dotnet test Nitrox.Test/Nitrox.Test.csproj`.
